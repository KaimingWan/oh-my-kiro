# v1.2.0

> First stable release — production-ready framework with 13 skills, 12 commands, and battle-tested hooks.

## Highlights

- **Data-Driven Skill Routing** — Context enrichment hook now uses regex-based trigger matching from skill frontmatter, replacing hardcoded keyword lists
- **OpenViking Semantic Search** — LLM query rewrite + dual search strategy achieves 100% hit rate on knowledge recall; gate filter + autocut for quality; OV-first enforcement blocks redundant filesystem search
- **@do Command** — Lightweight small-task workflow with mandatory scratchpad and context anchoring, preventing drift in multi-turn interactions
- **13 Skills** — Added omk-skill-creation (meta-skill), omk-youtube (subtitle extraction), omk-context7-docs, omk-coding, plus optimized all skill triggers with pushy descriptions
- **Lesson Recall Optimization** — Scenario-profiled indexing with episode top-hit display and LESSON injection into context
- **Ralph Loop Enhancements** — Autonomous Problem-Solving Protocol, QA verification, parallel reads, completion review, classify_exit
- **Review Command Worktree Support** — @review now respects `.active-submodule` to review submodule worktree code instead of only the root project
- **Hooks Sync** — Framework hooks auto-sync to downstream projects via sync-omk.sh Step 1.5
- **Archive Cleanup** — Removed 16K+ lines of fully-migrated v2 historical assets

## Breaking Changes

- All framework skills now use `omk-` prefix (e.g., `omk-planning`, `omk-coding`)
- Commands migrated from symlinks to `.kiro/prompts/` directory

## Bug Fixes

- sync-omk symlink shadowing resolved
- validate-project E5/E6/E7 test fixes
- yt-subtitle.sh early exit on glob miss
- test-split.sh SIGPIPE with pipefail
- Context enrichment dedup bypass for episode top-hit verify
- Markdown syntax verify handles YAML frontmatter in SKILL.md
